# Third-party icons — Game-Icons.net

The `assets/icons/game-icons/` directory vendors the complete
[Game-Icons.net](https://game-icons.net) collection (4239 SVG icons),
organized by contributor exactly as in the upstream repository
([github.com/game-icons/icons](https://github.com/game-icons/icons)). Each
sub-folder is named for the icon's author.

## License

The icons are provided under the **Creative Commons Attribution 3.0 Unported
(CC BY 3.0)** license — <https://creativecommons.org/licenses/by/3.0/> — except
those by _Viscious Speed_ and _Zeromancer_, which are **CC0** (public domain,
no attribution required).

CC BY 3.0 requires attribution. As requested upstream, include a mention
**"Icons made by {author}"** for each author whose icons you use, where the
author is the name of the sub-folder the icon came from. This file, retained in
the distribution, satisfies that requirement for the bundled set. The original
upstream notice is preserved alongside as `license.txt`.

## Modifications

CC BY 3.0 §4(a) requires indicating when the licensed material has been changed.
SoHL injects a theme-aware `@media (prefers-color-scheme: dark)` fill rule into
each SVG at build time (via `utils/svg-theme.mjs`) so the solid-black artwork
adapts to light and dark UI. The original artwork is otherwise unchanged. Icons
by _Viscious Speed_ and _Zeromancer_ are CC0, so this notice is a courtesy for
them rather than a requirement.

More info: <https://game-icons.net>
