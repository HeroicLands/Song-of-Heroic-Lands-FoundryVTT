_Song of Heroic Lands_ is built on the work of a great many people who gave their
art, their code, and their time away so that others could use it. This page names
them, records the licenses that work arrived under, and states what is and is not
covered by the licenses this project grants in turn.

If you are looking for the legal texts themselves rather than the credits, they
ship with the system: the code license is GPL-3.0-or-later and the content license
is CC BY-SA 4.0.
